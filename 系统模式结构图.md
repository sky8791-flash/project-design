## 设计模式协作图

```mermaid
classDiagram
    class Command {
        <<interface>>
        +execute()
        +undo()
    }
    
    class InsertCommand {
        +execute()
        +undo()
    }
    
    class DeleteCommand {
        +execute()
        +undo()
    }
    
    class FormatCommand {
        +execute()
        +undo()
    }
    
    class Memento {
        -state: String
        -timestamp: DateTime
        +getState()
        +getTimestamp()
    }
    
    class Caretaker {
        -historyStack: Memento[]
        -currentIndex: int
        +saveState()
        +undo()
        +redo()
    }
    
    class Subject {
        <<interface>>
        +attach(observer)
        +detach(observer)
        +notify()
    }
    
    class Document {
        -content: String
        -observers: Observer[]
        +updateContent()
        +notifyAll()
    }
    
    class Observer {
        <<interface>>
        +update(document)
    }
    
    class Collaborator {
        -userId: String
        +update(document)
    }
    
    class CommandInvoker {
        -commandHistory: Command[]
        +executeCommand(command)
        +undoLastCommand()
        +redoLastCommand()
    }
    
    class DocumentController {
        -document: Document
        -caretaker: Caretaker
        -invoker: CommandInvoker
        +handleOperation()
        +syncToAll()
    }
    
    Command <|-- InsertCommand
    Command <|-- DeleteCommand
    Command <|-- FormatCommand
    Subject <|-- Document
    Observer <|-- Collaborator
    DocumentController --> Command
    DocumentController --> Memento
    DocumentController --> Subject
    DocumentController --> Caretaker
    DocumentController --> CommandInvoker
    Collaborator --> Observer
```

## 操作流程图

```mermaid
sequenceDiagram
    participant User as 用户
    participant Editor as 编辑器
    participant WS as WebSocket服务
    participant Cmd as 命令调度器
    participant Doc as 文档服务
    participant OT as OT引擎
    participant DB as 数据库
    participant Others as 其他用户
    
    User->>Editor: 输入编辑操作
    Editor->>WS: 发送操作请求
    WS->>Cmd: 转发操作
    Cmd->>Cmd: 创建命令对象
    Cmd->>Doc: 执行前保存快照
    Doc->>DB: 保存备忘录
    Cmd->>OT: 执行操作
    OT->>OT: 冲突检测与转换
    OT->>Doc: 更新文档状态
    Doc->>DB: 保存操作日志
    Doc->>WS: 通知所有观察者
    WS->>Others: 广播更新
    Others->>Editor: 同步更新
    Editor->>User: 显示最新内容
```

## 数据库ER图

```mermaid
erDiagram
    USER ||--o{ DOCUMENT : creates
    USER ||--o{ OPERATION_LOG : performs
    DOCUMENT ||--o{ OPERATION_LOG : has
    DOCUMENT ||--o{ DOCUMENT_SNAPSHOT : has
    DOCUMENT {
        bigint id PK
        varchar title
        longtext content
        bigint created_by FK
        datetime created_at
        datetime updated_at
    }
    USER {
        bigint id PK
        varchar username
        varchar email
        varchar password_hash
        datetime created_at
    }
    OPERATION_LOG {
        bigint id PK
        bigint document_id FK
        bigint user_id FK
        varchar command_type
        json command_params
        int version
        datetime created_at
    }
    DOCUMENT_SNAPSHOT {
        bigint id PK
        bigint document_id FK
        longtext content
        int version
        datetime created_at
    }
```
